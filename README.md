
# Operation Phantom Swipe
## Digital Forensics Assignment

A simulated investigation of ATM skimming, credit card cloning and online financial fraud.

### Project Contents
- `evidence/` – Simulated device evidence folders
- `artifacts/` – Synthetic digital evidence files
- `scripts/` – Python forensic scripts
- `hashes/` – SHA-256 hash records
- `chain_of_custody/` – Evidence handling records
- `report/` – Investigation reports and analysis
- `password_protected/` – Password analysis simulation
- `screenshots/` – Project execution screenshots

### Tools Used
- Python 3
- GitHub
- GitHub Actions
- SHA-256
- MD5

### Execution
Run these commands from the repository root:

```bash
python scripts/analyze_evidence.py
python scripts/password_cracking.py
python scripts/generate_hashes.py
```

### Disclaimer
All evidence and activities are fictional and created strictly for academic purposes. No real financial data or devices were accessed.
